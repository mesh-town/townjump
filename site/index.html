Share a local port with anyone who has the key

townjump opens a direct, encrypted connection between two machines behind their routers and forwards one TCP or UDP port over it. No account. One static binary; works with the original Holesail.

  • No port forwarding
  • No server
  • No Node.js
Install See how it works

Free and open source (AGPL-3.0). macOS, Windows, Linux, OpenWrt and Keenetic routers, Termux, Docker.

# on the machine with the service
$ townjump --live 3000
  hs://s000…   # the key

# on the other machine
$ townjump hs://s000…
  http://127.0.0.1:8989

What you do not have to do

  • Open a port. The two sides find each other in the public DHT and punch through NAT.
  • Run a server. Data goes directly between the peers; DHT nodes only help them meet.
  • Install Node.js. On routers it is a package.
  • Create an account. Whoever has the key can connect.
  • Learn new commands if you use Holesail. Same options, same hs:// keys.

Not the tool if you need

  • Many devices and ports with names and a member list: that is Mesh Town, built on townjump.
  • A whole subnet: townjump forwards one port.
  • Holesail 3.x keys: only the 2.4.4 protocol.

Install

macOS

Homebrew

brew install mesh-town/macos/townjump

Download

curl -fLO https://mesh-town.github.io/townjump-dist/macos/townjump-macos-aarch64.tar.gz
tar -xzf townjump-macos-aarch64.tar.gz --strip-components=1 '*/townjump'
xattr -d com.apple.quarantine townjump

Intel: townjump-macos-x86_64.tar.gz.

Windows

Download townjump-setup.exe. If SmartScreen warns, choose More info, then Run anyway. The installer adds townjump to PATH.

Linux

Debian / Ubuntu

arch="$(dpkg --print-architecture)"
curl -fLO "https://mesh-town.github.io/townjump-dist/linux/debian/townjump_${arch}.deb"
sudo apt install "./townjump_${arch}.deb"

Other Linux

curl -fLO https://mesh-town.github.io/townjump-dist/linux/townjump-linux-$(uname -m).tar.gz
tar -xzf townjump-linux-$(uname -m).tar.gz --strip-components=1 --wildcards '*/townjump'

Android

In Termux:

curl -fLO https://mesh-town.github.io/townjump-dist/android/townjump-termux-aarch64.tar.gz
tar -xzf townjump-termux-aarch64.tar.gz --strip-components=1 --wildcards '*/townjump'
mv townjump $PREFIX/bin/

Router

OpenWrt

wget -O- https://mesh-town.github.io/townjump-openwrt/install.sh | sh

Keenetic

wget -O- https://mesh-town.github.io/townjump-keenetic/install.sh | sh

The package installs /usr/bin/townjump and starts nothing; run it from an init script of your own.

Docker

docker run --rm ghcr.io/mesh-town/townjump:latest --help

Then: townjump --live 3000 on one side, townjump <key> on the other. Verify downloads against SHA256SUMS of the release. All channels, updates and removal: docs/installing.md.

How it works

  1. The server derives a key pair from the secret in the key and announces its public key in the DHT.
  2. The client derives the same public key, finds the server through DHT nodes, and the two punch a hole through their NATs over UDP.
  3. Data flows directly in an end-to-end encrypted Noise stream over UDX, a reliable transport on UDP. If the hole punch fails, a DHT relay node carries the stream until a direct path works.
  4. The client listens on 127.0.0.1:8989 and forwards every connection to the server's port.

Works with Holesail

townjump is an independent port of Holesail 2.4.4, not affiliated with Holesail or Liveport. A townjump server serves JavaScript clients and the other way round, over TCP and UDP, with private and public keys. The command line and help text are those of holesail, so existing scripts keep working. The binary is named townjump, so it installs next to the npm package. Differences.

Use it from Rust

The crates townjump, townjump-client, townjump-server and townjump-dht expose a Holesail facade. Depend on a git tag; the API is not stable and the crates are not on crates.io. See docs/library.md.

FAQ

Is the key a password?

A private key (hs://s000…) is the secret. A public key (--public) can be published and anyone can connect, so protect the service itself.

Does it work behind a mobile operator's NAT?

Usually. Where hole punching fails, a DHT relay node carries the stream; if both sides change ports per connection, it may not connect.

Does it reconnect by itself?

No, like Holesail: restart the client. --key keeps a server's key across restarts.

Can I share a folder?

townjump --filemanager <dir> serves a web file manager; use --safe-mode and a password.
